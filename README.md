# Sistema de Gestión de Parqueadero

## 1. Descripción del proyecto

Sistema de software diseñado para facilitar la administración y el control de un parqueadero, permitiendo gestionar el ingreso y salida de vehículos, consultar la disponibilidad de espacios y llevar un registro de los vehículos que utilizan el servicio.

## 2. Objetivo

Desarrollar una solución de software que permita optimizar los procesos de administración de un parqueadero mediante el registro, seguimiento y control de los vehículos, mejorando la organización y el manejo de la información.

## 3. Problema que busca resolver

En algunos parqueaderos, el control de los vehículos y la disponibilidad de espacios se realiza de manera manual, lo que puede generar errores en los registros, dificultades para identificar los espacios disponibles y problemas al calcular los tiempos de permanencia.

Este proyecto busca solucionar estas dificultades mediante un sistema que centralice la información y facilite la gestión de las operaciones del parqueadero.

## 8. Ejecución del proyecto

1. Clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Verificar que Python esté instalado.
4. Ejecutar el archivo principal:

```bash
python src/main.py
```
